Diagnostics & Optimization Audit (ce-debug + ce-optimize + ce-ideate)

HomeGym Architecture & UX Decluttering

Grounded audit of redundant features, dead telemetry, and over-engineered legacy mechanics that add cognitive friction to daily training.

1. Diagnostic Findings: Redundant & Obsolete Mechanics (Identified via ce-debug)
Programme Start/Finish Dates Purge
🚨 The Issue: startDate calculates a rigid (days / 7) % 9 week modulo from an ancient hardcoded date. When deload was globally disabled, this date math became completely dead in calculation logic, yet SettingsModal still prompts users to type dates.
💡 Remedy: Remove the "Program start dates" section in SettingsModal. Decouple routines from calendar start dates; workouts are naturally sequenced by Day of Week (Monday, Tuesday, etc.) or Rolling Session Index.
Outcome: Eliminates confusing date inputs, eliminates dead Re(startDate) date math, and prevents artificial "Week 7 of 9" desync.
Dead-Letter Queue in Settings Purge
🚨 The Issue: SettingsModal displays developer-internal telemetry: "Dead-Letter Queue: 0 unprocessable mutations" and "Clear Dead-Letter Queue". Users have no reason to see database retry queues in a personal gym tracker.
💡 Remedy: Move offline retry/error handling strictly into background error logging. Strip the dead-letter UI and manual sync buttons from user-facing Settings.
Outcome: Clean Apple HIG Settings sheet focusing on user preferences (Theme, Household Key, Workout Reminders, Backup Export).
Program Creation Wizard Modal Purge
🚨 The Issue: ProgramWizardModal is a 600-line multi-step wizard generating legacy rigid 4-block ladders. It is completely superseded by the direct Plan table editor and the new Physio & AI Assistant.
💡 Remedy: Remove ProgramWizardModal from PlanView overflow menu. Direct plan editing + AI Routine Assistant handle 100% of routine creation and adaptation.
Outcome: Cuts ~600 lines of dead modal code, removes UI clutter from Plan tab, and establishes a single canonical routine evolution path.
Dual Sync (plateplan vs active_program) Consolidate
🚨 The Issue: Every routine edit writes identical payloads to two separate RTDB paths: gym_users/${userId}/active_program/current AND gym_users/${userId}/plateplan/current, plus duplicate localStorage keys.
💡 Remedy: Unify on gym_users/${userId}/active_program/current as the sole canonical routine path. Read/write to one key, eliminating race conditions.
Outcome: Halves cloud database write traffic, eliminates sync desynchronization, and simplifies state hydration.
Calendar Reminders (.ics) Export Purge
🚨 The Issue: In the Plan tab overflow menu, "Download reminders (.ics)" generates a static calendar file based on the deprecated 9-week schedule that quickly goes stale.
💡 Remedy: Remove handleDownloadReminders. Real push notifications (already built into HomeGym via notifications.js) handle actual daily workout reminders cleanly.
Outcome: Removes dead menu item and prevents broken calendar imports into Apple/Google Calendar.
Reset to Default Program Button Purge
🚨 The Issue: Plan tab overflow has a red "🔄 Reset to default program…" button that replaces current tailored routines with hardcoded default exercises from 2024 (I.K).
💡 Remedy: Remove this destructive reset button. Users already have Version Milestones with safe one-tap rollback to restore verified baseline routines.
Outcome: Eliminates catastrophic accidental reset risk and cleans up overflow menu.
